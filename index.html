How to read this view

Every frame is one clock cycle of a real Icarus Verilog simulation of the RTL in Final/…/ooo_rtl (board top top_fpga_ooo, default build: speculation on, 2-way write-back L1, slow data memory). gen_trace.py compares every commit with the reference model (tools/ref_model.py traces) when it saves a trace, and the badge next to the program menu shows the result.

A frame shows the state during the cycle. The highlighted arrows show the transfers that happen at the end of that cycle, on the next rising edge: dispatch into an RS or the LSQ, issue to a unit, a broadcast on a CDB, a commit into the register file.

Each ROB entry has its own colour. Its tag chip (T0…) is the same colour wherever that instruction appears, so you can follow one instruction around the machine. Hover a chip to highlight it everywhere. A dashed chip means "waiting for this tag".

The four CDBs (ALU, MUL, DIV, LSU) run down the right side of the units, write into the ROB, and loop round to the RS and LSQ inputs on the left. Every consumer listens to all four buses.
